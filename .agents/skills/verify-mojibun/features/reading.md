# reading

Reading Passages and Batch Text episodes (`slices/reading`, issue #94). A Learner rereads the stories generated for them after Learn batches, taps Words for lookups and Sentences for translations. Practice Text passages (`slices/reading/practice`, issue #111) are generated by Learners on a Cleared Level.

## Sub-features

- **Episode list** (`/reading`): the Learner's own Batch Texts grouped per level (N5 to N1, then Unlevelled), episodes in order, each a link "Episode N: <title>". A text whose passage is not approved yet is left out. With none: "No stories yet."
- **Text screen** (`/reading/texts/:id`, `/reading/passages/:id`): title, "Episode N · level" for a Batch Text, Sentences in order with Words as buttons. Words of the Batch Text's batch carry `data-in-batch="true"`.
- **Tap-to-translate**: each Sentence with a translation has a "Show translation" button; the English stays hidden until tapped.
- **Lookup**: tapping a Word shows its form, reading and meanings in a status region and logs a `lookup` Review (`POST /api/reading/lookups`). It never introduces the Word or feeds the scheduler.
- **Furigana** per the Learner's `furigana` preference: On = every Word with kanji, Off = none, Mixed (default) = only Words still New (unlinked Words count as New).
- **Practice texts** (`/reading/practice`, linked from `/reading`): heading "Practice texts". With no Cleared Level (every unsuspended Kanji of a level Known) it says "Practice texts open once you know every kanji of a JLPT level." and shows no form. Otherwise a Generate form with selects only (Level = cleared levels, Passage type, Length, Topic from a fixed list) and no text input. "Generate" posts the choices, waits up to 20 s, then opens `/reading/practice/:id` (tap-to-translate and lookups as for Batch Texts) or says "Your text is still being made. It will appear in your library when it is ready." Below, "Your library" lists the Learner's own Practice Texts ("Still being made" until approved). At 5 in a rolling 24 h it says "Try again tomorrow."
- **API**: `GET /api/reading/episodes`, `GET /api/reading/batch-texts/:id`, `GET /api/reading/passages/:id`, `POST /api/reading/lookups`, `GET /api/reading/practice/options`, `POST /api/reading/practice/texts`, `GET /api/reading/practice/texts`, `GET /api/reading/practice/texts/:id` (owner only).

## How to get to it (user POV)

Sign in, then "Reading" in the nav (`/reading`). Pick an episode.

## Driving it with Playwright

Preconditions:

- The Compose stack, API and web app are up (the `verify-mojibun` skill does this) and the browser has a Learner session.
- A fresh Learner has no Batch Texts, so the page shows "No stories yet." To exercise the text screen, seed an approved Reading Passage (with Sentences, tokens and `sentence_uses_word` links) and a `progress` Batch Text row for the Learner pointing at it. `/reading/passages/<id>` needs only the passage.

Steps:

1. `page.goto("/reading")`; expect the heading "Reading", then an "Episode N:" link or "No stories yet."
2. Open the episode; click "Show translation" and expect that button to disappear for the Sentence.
3. Click a Word button; expect the lookup status region, and a `lookup` entry in the Learner's Review log.
4. Change the `furigana` preference (On, Off, Mixed), reload, and expect `rt` elements to follow the rule.

5. For Practice Texts, seed Known progress for every unsuspended Kanji of N5 (otherwise the page shows the locked message), open `/reading/practice`, press Generate, and expect either the text screen or the library notice; after 5 texts expect "Try again tomorrow.".

The specs are `slices/reading/tests/reading.spec.ts` (an episode or the empty state is accepted) and `slices/reading/tests/practice.spec.ts` (locked state or the form).

## Gotchas

- Furigana readings come from the stored Sudachi tokens (katakana, shown as hiragana). A Sentence without tokens renders as one plain run.
- Only Words linked by `sentence_uses_word` are tappable; particles and unlinked Words are plain text.
- Not built: highlighting earlier items (the Batch Text record stores only the batch's items), Grammar Point highlighting, reading from the end of Learn (#learn slice).
- Practice Texts need the worker running with an LLM key to turn a request into a text; without it every request ends in the library as "Still being made". The shared Learner-triggered token budget is not shown to the Learner: when it is spent the text simply stays in the library until the budget resets.
